# Security Policy

## Reporting a vulnerability

Report security vulnerabilities in private through GitHub private vulnerability reporting:

https://github.com/gwenjs/gwen/security/advisories/new

Do not open a public issue for a security report.

## Response

We acknowledge a report within 3 business days.
We triage a report within 7 days.

## Trust model

What the engine trusts, what it checks, and what the host must do is recorded in [ADR 0004](internals-docs/adr/0004-trust-model.md).
